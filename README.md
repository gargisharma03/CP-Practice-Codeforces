# CP Practice — Codeforces

A organized repository containing my C++ solutions to Competitive Programming problems from [Codeforces](https://codeforces.com/).

## 📂 Repository Structure

Problems are categorized by their Codeforces problem tags/difficulty levels within contests or problem sets:

```text
├── A/  # Division 2 / 3 Problem A solutions
├── B/  # Division 2 / 3 Problem B solutions
├── C/  # Division 2 / 3 Problem C solutions
├── D/  # Division 2 / 3 Problem D solutions
└── ...
```

+ Platform: Codeforces
